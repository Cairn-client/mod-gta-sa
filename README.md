# CoopAndreas on Cairn

A fork of [Tornamic/CoopAndreas](https://github.com/Tornamic/CoopAndreas), the multiplayer mod for **Grand Theft Auto: San Andreas**, made to run on the [Cairn launcher](https://github.com/Cairn-client/launcher).

## What we changed

- A Cairn pack: the mod is published as a pack the launcher installs and updates; Play starts the game through the mod's launcher.

The mod's own code and credits are its authors'. Everything else is as upstream; see [UPSTREAM.md](UPSTREAM.md) for the version this fork is based on.

## Play it

1. Install [Cairn](https://github.com/Cairn-client/launcher/releases/latest).
2. Open Grand Theft Auto: San Andreas in the Library, download the mod and press Play.

It needs the 1.0 US version of the game.

Each release of this repository is the pack the launcher downloads.
